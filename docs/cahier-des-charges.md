  - Partie II : plateforme du CNTS (rôles, format des codes, parcours d'une poche,
    fonctionnalités P1 à P13) ;
  - Annexe A : architecture technique ;
  - **Annexe B : la base de données (les 28 tables)** — source du schéma SQL
    `supabase/migrations/0001_schema_initial.sql` ;
  - Annexe C : le contrat d'API (routes) ;
  - Annexe D : organisation du travail ;
  - **Annexe E : les valeurs provisoires à valider avec le CNTS** (délais, seuils,
    durées de conservation…) — reprises dans `supabase/seed/seed.sql` et la table `regles`.
